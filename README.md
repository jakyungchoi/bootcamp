# 원티드랩 부트캠프 교육사업 웹페이지

Home + 4개 핵심 페이지(운영 교육 과정 / 교육 관리 / 교육 문화 / 참여 기업 연계) + **관리자
페이지(`/admin`)** 를 Next.js + Tailwind CSS + Supabase로 구현했습니다. 공개 페이지의 거의
모든 텍스트/이미지/카드 항목을 관리자 페이지에서 코드 수정 없이 바로 바꿀 수 있습니다.

## 지금 상태

- Supabase를 아직 연결하지 않아도 `src/lib/content.ts`의 예시 데이터로 5개 공개 페이지가
  전부 정상 동작합니다. (`npm run dev`로 바로 확인 가능)
- 데이터 조회 코드(`src/lib/data.ts`)는 Supabase 연결 여부를 자동으로 감지해서, Supabase가
  연결되어 있으면 실제 DB 데이터를, 아니면 예시 데이터를 보여줍니다.
- **관리자 페이지(`/admin`)가 완성되어 있습니다.** 로그인 후 사이트의 로고/문구/카드/과정
  등을 목록에서 추가·수정·삭제·순서 변경·공개-비공개 전환할 수 있고, 이미지도 직접
  업로드할 수 있습니다. Supabase 연결 + 관리자 계정 생성이 끝나면 바로 사용할 수 있습니다.

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

`http://localhost:3000` 에서 확인할 수 있습니다. (Supabase 연결 전에는 예시 데이터로
동작하고, 관리자 페이지는 "Supabase가 아직 연결되지 않았습니다" 안내만 보여줍니다.)

## 1단계 · Supabase 연결하기

1. [supabase.com](https://supabase.com) 에서 새 프로젝트를 만듭니다. (무료 플랜으로 시작 가능)
2. 프로젝트의 **SQL Editor** 메뉴에 들어가서 이 저장소의 `supabase/schema.sql` 내용을
   그대로 붙여넣고 실행합니다. (테이블 생성 + RLS 보안 정책 + 이미지 저장 공간 + 기본
   시드 데이터가 한 번에 들어갑니다. 이미 한 번 실행했더라도 다시 실행해도 안전합니다.)
3. 프로젝트의 **Settings > API** 메뉴에서 "Project URL"과 "anon public" 키를 복사합니다.
4. 이 저장소 루트에서 `.env.example`을 `.env.local`로 복사하고, 방금 복사한 값을 채워
   넣습니다.

   ```bash
   cp .env.example .env.local
   ```

   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
   ```

5. 개발 서버를 재시작하면 화면이 `content.ts` 예시 데이터 대신 Supabase의 실제 데이터를
   보여줍니다.

### Supabase 무료 플랜 참고사항

- DB 500MB, 스토리지 1GB, 대역폭 5GB까지 무료입니다. 이 사이트 규모에는 충분합니다.
- **7일간 아무 활동이 없으면 프로젝트가 자동으로 일시정지(pause)** 됩니다. 다시 접속하면
  대시보드에서 수동으로 재개할 수 있지만, 운영 중인 사이트라면 이 점을 감안해서 유료 플랜
  (Pro, $25/월~) 전환을 고려해야 합니다.
- 무료 프로젝트는 계정당 최대 2개까지 동시에 활성화할 수 있습니다.

## 2단계 · 관리자 계정 만들기 (팀 공용 계정 1개)

관리자 페이지는 팀에서 계정 1개를 공유해서 사용하는 방식으로 되어 있습니다. 아래 순서로
한 번만 설정하면 됩니다.

1. Supabase 대시보드 왼쪽 메뉴 **Authentication > Users** 로 들어갑니다.
2. **Add user** 버튼을 눌러 "Create new user"를 선택합니다. 팀에서 사용할 이메일과
   비밀번호를 입력하고, **Auto Confirm User**를 체크한 뒤 생성합니다. (이메일 인증 절차 없이
   바로 로그인 가능한 계정이 만들어집니다)
3. 방금 만든 사용자 목록에서 UUID(예: `a1b2c3d4-...` 형태의 긴 문자열)를 복사합니다.
4. 다시 **SQL Editor**로 가서 아래 SQL을 실행합니다. `여기에_UUID_붙여넣기`와
   `여기에_이메일_붙여넣기` 부분만 방금 복사한 값으로 바꿔주세요.

   ```sql
   insert into admin_users (id, email, name, role)
   values ('여기에_UUID_붙여넣기', '여기에_이메일_붙여넣기', '팀 공용 관리자', 'ADMIN');
   ```

5. 이제 사이트의 `/admin` (예: `http://localhost:3000/admin` 또는 배포 주소 + `/admin`)으로
   접속해서, 2번에서 만든 이메일/비밀번호로 로그인하면 됩니다. 이 계정 정보를 팀원들과
   공유하면 누구든 같은 계정으로 접속해서 콘텐츠를 수정할 수 있습니다.

> 팀원별로 계정을 따로 만들고 싶다면 1~4번을 반복하면 됩니다. `admin_users.role`을
> `SUPER_ADMIN` / `ADMIN` / `EDITOR` 중 하나로 지정할 수 있도록 스키마에 미리 만들어
> 두었지만, 지금 버전의 관리자 페이지는 역할과 상관없이 admin_users에 있으면 모두 동일한
> 권한(전체 수정)을 가집니다.

## 3단계 · 이미지 업로드 확인

`schema.sql`을 실행하면 이미지 업로드용 저장 공간("media" 버킷)도 함께 만들어집니다.
별도 설정 없이 관리자 페이지에서 이미지 선택만 하면 자동으로 업로드됩니다. 혹시
업로드가 안 된다면 Supabase 대시보드 **Storage** 메뉴에 "media"라는 이름의 버킷이
공개(Public)로 만들어져 있는지 확인해주세요.

## 관리자 페이지에서 무엇을 바꿀 수 있나요

`/admin`에 로그인하면 왼쪽 메뉴에서 아래 항목들을 각각 목록으로 보고 추가·수정·삭제·
순서 변경·공개-비공개 전환할 수 있습니다.

### 왼쪽 메뉴 구분선

왼쪽 사이드바 메뉴는 어떤 공개 페이지에 속하는지 기준으로 그룹으로 묶여 있고, 그룹이
바뀌는 지점마다 구분선과 회색 소제목(전역 설정 / 운영 교육 과정 페이지 / 교육 문화 페이지 /
교육 관리 페이지 / 참여 기업 연계 페이지)이 표시됩니다. 처음 보는 사람도 어떤 메뉴가 어떤
화면과 연결되어 있는지 한눈에 알 수 있도록 하기 위한 것이고, "새 탭 추가"로 만든 페이지는
맨 아래 "추가한 페이지" 그룹으로 따로 모입니다.

### 편집 화면 옆 실시간 미리보기

콘텐츠를 관리하는 화면(교육 영역 카테고리, 대표 교육 과정, 협업 사례 등 거의 모든 메뉴)에는
오른쪽에 실제 공개 화면이 그대로 보이는 "실시간 미리보기" 패널이 함께 붙어 있습니다. 저장에
성공하면 이 미리보기도 자동으로 새로고침되어서, 공개 페이지를 새 탭으로 열어서 확인하러
왔다갔다 할 필요 없이 한 화면에서 바로 결과를 볼 수 있습니다. 미리보기는 실제 페이지를 그대로
띄운 것이라 "참여 신청하기" 버튼 같은 것도 그 안에서 직접 눌러볼 수 있습니다. 패널 우측 상단의
새로고침 아이콘으로 언제든 수동으로도 새로고침할 수 있고, 새 탭 아이콘을 누르면 그 화면을 완전히
새 탭에서 열 수 있습니다. (화면이 좁은 태블릿/모바일에서는 미리보기가 아래로 내려가고, "미리보기
보기/숨기기" 버튼으로 접었다 펼 수 있습니다)

- 사이트 전역 설정 — 로고, 사이트 이름, 홈 화면 히어로 제목/부제목/이미지, **헤더 메뉴**와
  **홈 화면 핵심 영역 카드**(둘 다 자유롭게 추가/삭제/수정 가능 — 4개로 고정되어 있지
  않고, 서로 개수/내용이 달라도 됩니다). 홈 화면 카드의 "카드 설명"은 그 페이지에 실제로
  들어갔을 때 맨 위에 나오는 설명(페이지 상단 문구)과는 완전히 별개의 문구라, 서로 다르게
  써도 됩니다.
- **페이지 상단 문구** — 4개 주요 페이지(운영 교육 과정 / 교육 관리 / 교육 문화 / 참여
  기업 연계) 맨 위에 나오는 영문 소제목 · 큰 제목 · 그 아래 설명 문단(예: 교육 문화 페이지의
  "원티드랩에서 교육을 받으면...")을 여기서 수정합니다. 각 페이지의 세부 콘텐츠(카드, 목록 등)를
  관리하는 화면에는 "이 화면 바로 위, 페이지 맨 위 문구는 여기가 아니라 페이지 상단 문구
  메뉴에서 수정합니다"라는 안내와 바로가기 링크가 표시됩니다.
- 교육 영역 카테고리, **과정 기간 분류**(단기/중장기 등 — 대표 교육 과정을 이 분류로
  묶어서 보여줍니다), 대표 교육 과정(**프로젝트 상세**를 등록하면 방문자가 과정을 클릭했을
  때 좌우로 넘겨보는 팝업이 뜹니다), 커리큘럼 구성 단계 (운영 교육 과정 페이지)
- 교육 문화 프로그램 (교육 문화 페이지 — **사진**을 여러 장 등록하면 카드에서 좌우로
  미끄러지듯 넘겨볼 수 있는 슬라이드로 표시됩니다. 한 장만 등록해도 됩니다. 여러 장이면 4초마다
  자동으로도 다음 사진으로 넘어가고, 마우스를 올려두면 잠시 멈춥니다. 마지막 사진에서 첫
  사진으로 넘어갈 때도 끊기지 않고 계속 미끄러집니다)
- **교육 성과 지표**(상단 숫자 카드 + 강조 타일 — 카드 배경에는 브랜드 색 그라데이션을 넣고,
  숫자 글씨 자체는 어떤 배경에서도 또렷하게 읽히도록 검정색(다크 모드는 흰색)으로 다듬었습니다),
  **오프라인 교육장**(전체 설명 + 사진 슬라이드 + 특징 카드로 구성된 새 섹션 — 자세한 내용은
  바로 아래 참고), 학습자 관리 카드, 학습부진자 지도 계획, **개월차별 관리**(카드가 아니라
  한눈에 보는 가로 막대그래프 형태 — 자세한 내용은 바로 아래 참고), 교육 품질 관리, 협업 도구
  (교육 관리 페이지). **교육 성과 지표 / 학습자 관리 / 학습부진자 지도 계획 / 개월차별 관리 /
  교육 품질 관리** 다섯 메뉴는 모두 제목 바로 아래 한 줄 설명을 이 메뉴 화면 위쪽에서 바로
  수정할 수 있습니다(다른 메뉴들과 동일한 방식).
- **개월차별 관리** (교육 관리 페이지) — 예전에는 개월차마다 별도 카드로 나열됐는데, 이제는
  가운데 가로선(트랙) 위에 구간마다 동그란 점을 찍고, 그 위/아래로 번갈아가며 카드(기간
  배지·제목·설명)를 붙이는 **로드맵 형태**로 바뀌었습니다. 관리자 화면에서 각 구간을 "시작
  개월차"와 "종료 개월차"로 등록하면(예: 시작 1 / 종료 2 → "1~2개월차"), 이 메뉴 맨 위
  "타임라인 설정"에서 지정한 **전체 교육 기간**(예: 가장 긴 과정이 6개월이면 6) 대비 그
  구간이 차지하는 개월 수만큼 트랙에서의 너비가 정해집니다. 예를 들어 전체 6개월 중
  "1~2개월차"로 등록한 구간은 트랙 전체 너비의 2/6을 차지합니다. 아직 구간으로 등록하지 않은
  개월은 얇은 회색 트랙으로 표시되어 전체 기간이 한눈에 보이고, 트랙 아래에는 "1개월차 · 총
  N개월 과정 · N개월차" 안내가 붙어 전체 기간 감각을 잡아줍니다. 카드나 점을 클릭하면 기존과
  동일하게 등록한 사진을 좌우로 넘겨보는 팝업이 뜹니다(사진을 등록하지 않은 구간은 클릭되지
  않습니다). 공개 화면에는 관리자 목록의 위/아래 순서가 아니라 "시작 개월차" 순서대로
  왼쪽부터 표시됩니다.
- **오프라인 교육장** (교육 관리 페이지의 새 메뉴) — 전체 설명 문구 하나, 사진 슬라이드(교육
  문화 프로그램과 똑같은 방식으로 한 장만 등록해도 되고, 여러 장이면 좌우로 넘겨볼 수 있고
  마지막 사진에서 첫 사진으로 넘어갈 때도 끊기지 않고 이어집니다), 그 아래 짧은 특징 카드
  목록(제목 + 한 줄 설명, 예: "매일 다니기 편한 역세권 캠퍼스" / "구로디지털단지역 도보
  10분")으로 구성됩니다. 특징 카드는 개수 제한 없이 자유롭게 추가·삭제·순서 변경할 수
  있고, 처음에는 예시로 4개가 채워져 있으니 실제 캠퍼스 소개 문구로 바꾸거나 지우고
  새로 만들면 됩니다.
- **이런 협업이 가능해요** — 제목 바로 아래 한 줄 설명(안내 문구)을 이 메뉴 화면 위쪽에서
  바로 수정할 수 있습니다. 그 아래 활동 이름 목록(알약 모양 태그)은 기존처럼 목록으로
  추가·수정·삭제·순서 변경합니다.
- **협업 사례** — 제목 바로 아래 한 줄 설명을 이 메뉴 화면 위쪽에서 바로 수정할 수 있습니다.
  그 아래는 기존처럼 로고 이미지 목록입니다(등록한 로고 이미지가 옆으로 끊김 없이 계속 흐르는
  띠 형태로 표시되고, 마우스를 올리면 기업명이 말풍선으로 뜹니다. 제목/설명 입력칸은 공개
  화면에는 보이지 않는 내부 기록용입니다) (참여 기업 연계 페이지)
- **기업 참여 방식** — 제목 바로 아래 한 줄 설명을 이 메뉴 화면 위쪽에서 바로 수정할 수
  있습니다. 공개 화면에는 이 섹션의 제목·설명과 "참여 신청하기" 버튼만 보이고, 카드 목록은
  표시되지 않습니다. 여기 등록한 항목의 제목은 대신 **참여 신청하기** 팝업 폼의 "참여 희망
  방식" 체크박스 목록에 그대로 쓰입니다(설명/아이콘은 내부 기록용). "참여 신청하기" 버튼을
  누르면 팝업 폼이 뜨고, 제출 내용은 구글 시트에 자동으로 기록됩니다 — 연동 설정 방법은 아래
  "참여 신청 폼 → 구글 시트 연동 설정" 항목을 참고하세요. 연락처 입력칸은 숫자만 입력해도
  자동으로 "010-0000-0000" 모양으로 하이픈이 붙습니다. (참여 신청하기 버튼은 구글 시트 연동
  주소가 설정되어 있어야 보입니다) **팝업 폼 자체의 설정은 예전에는 "사이트 전역 설정"에
  있었지만, 이제는 이 "기업 참여 방식" 화면(콘텐츠 목록 바로 위)으로 옮겨졌습니다** —
  선택지(만남 방식), 개인정보 동의 문구, 제출 완료 안내 문구에 더해 아래 두 가지를 새로
  다룰 수 있습니다.
  - **기본 제공 10개 항목(기업명/담당자명/부서/직급/이메일/연락처/참여 희망 방식/만남
    방식/문의·요청 내용/남기실 말씀)** — 각 항목마다 "표시" 체크박스로 폼에서 완전히
    숨길 수 있고(사실상 삭제와 같은 효과입니다 — 구글 시트 열 구조 때문에 진짜로 항목
    자체를 지울 수는 없어서, 숨김으로 대신합니다), "필수" 체크박스로 필수/선택을 정하고,
    "이름" 칸에서 화면에 실제로 보이는 라벨 문구를 자유롭게 바꿀 수 있습니다(예: "남기실
    말씀 (선택 작성)" → "남기실 말씀"). 표시를 꺼둔 항목은 필수 여부와 상관없이 제출 시
    검사하지 않습니다.
  - **직접 추가하는 항목** — "항목 추가" 버튼으로 완전히 새로운 한 줄 입력 항목을 만들 수
    있습니다. 이름과 필수 여부를 정하고, 목록 순서도 위/아래 화살표로 바꿀 수 있고,
    휴지통 아이콘으로 삭제할 수도 있습니다. **다만 이렇게 추가한 항목의 값은 구글 시트에
    기존 10개 열 뒤에 이 목록 순서 그대로 추가 열로 기록되므로, 항목을 추가·삭제·순서
    변경했다면 구글 시트 1행의 머리글도 반드시 같은 순서로 맞춰줘야 합니다** (아래 "참여
    신청 폼 → 구글 시트 연동 설정" 항목 참고).

저장하면 코드 재배포 없이 공개 페이지에 바로 반영됩니다. "설명" 종류의 입력칸(여러 줄 입력이
가능한 칸)에 줄바꿈을 넣으면, 공개 화면에도 입력한 줄바꿈 그대로 표시되고, 줄이 길어서 자동으로
줄바꿈되는 부분은 양쪽 정렬되어 줄 끝이 가지런히 맞춰집니다.

### 관리자 대시보드 탭 관리 (추가 / 삭제 / 이름 변경 / 순서 변경)

`/admin` 대시보드 화면 자체에서 각 카드(탭) 아래에 있는 아이콘으로 아래 작업을 할 수
있습니다.

- **연필 아이콘** — 탭 이름을 바꿉니다. 바꾼 이름은 왼쪽 사이드바 메뉴뿐 아니라, 그 항목을
  누르고 들어간 **콘텐츠 관리 화면 자체의 제목**과, 운영 교육 과정 / 교육 관리 / 참여 기업
  연계 페이지의 해당 섹션 제목까지 세 곳 모두에 한 번에 반영됩니다. 예전에는 사이드바 이름만
  바뀌고 콘텐츠 관리 화면 제목은 그대로 남아있어서 같은 항목이 서로 다른 이름으로 보이는
  경우가 있었는데, 이 버전부터는 그런 불일치가 생기지 않습니다. (사이트 전역 설정, 페이지
  상단 문구, 교육 문화 프로그램은 관리자 메뉴 이름만 바뀌고 공개 화면 문구는 각 항목 편집
  화면 또는 "페이지 상단 문구"에서 따로 수정합니다.)
- **↑ / ↓ 아이콘** — 탭 순서를 바꿉니다. (왼쪽 사이드바 메뉴 순서에도 그대로 반영됩니다.
  **교육 성과 지표 / 오프라인 교육장 / 학습자 관리 카드 / 학습부진자 지도 계획 / 개월차별
  관리 / 교육 품질 관리** 여섯 개는 여기서 바꾼 순서가 **교육 관리 페이지에 실제로 나열되는
  섹션 순서**에도 그대로 반영됩니다 — 예를 들어 "오프라인 교육장"을 위/아래 화살표로 "학습자
  관리 카드"보다 앞으로 옮기면, 공개 화면에서도 오프라인 교육장 섹션이 학습자 관리 카드보다
  먼저 나오고 번호(01, 02, ...)도 그 순서에 맞춰 다시 매겨집니다. 다른 페이지의 탭들은
  지금처럼 사이드바 순서만 바뀝니다.)
- **눈 아이콘 (기존 메뉴)** — 메뉴에서 숨기거나 다시 표시합니다. 숨겨도 데이터 자체는 삭제되지
  않으니 언제든 다시 표시할 수 있습니다. 운영 교육 과정 / 교육 관리 / 참여 기업 연계 페이지의
  섹션(교육 영역, 대표 교육 과정, 커리큘럼 구성 단계, 학습자 관리, 학습부진자 지도 계획,
  개월차별 관리, 교육 성과 지표, 교육 품질 관리, 협업 도구, 기업 참여 방식, 이런 협업이
  가능해요, 협업 사례)은 숨기면 공개 화면에서도 그 섹션 전체가 함께 사라지고, 남은 섹션
  번호(01, 02, ...)가 자동으로 다시 매겨집니다. (사이트 전역 설정, 페이지 상단 문구, 교육
  문화 프로그램은 관리자 메뉴에서만 숨겨지고 공개 화면은 그대로입니다.)
- **새 탭 추가 버튼** — 완전히 새로운 탭(페이지)을 만듭니다. 이름을 입력하면 바로 편집
  화면으로 이동하고, 제목/설명/카드 내용을 자유롭게 채운 뒤 "저장"하면 `/pages/주소`
  (예: `/pages/faq`)로 즉시 공개됩니다. 이렇게 만든 탭은 **휴지통 아이콘으로 완전히
  삭제**할 수도 있습니다.
- 새로 만든 탭을 헤더 메뉴에도 넣고 싶다면, "사이트 전역 설정 > 헤더 메뉴"에서 메뉴를
  추가하고 링크 주소에 `/pages/주소`를 입력해주세요. (헤더 메뉴와 홈 화면 카드는 서로
  별개라, 홈 화면에는 안 넣고 헤더 메뉴에만 추가하는 것도 가능합니다)

> 기존 12개 메뉴(교육 영역 카테고리, 대표 교육 과정 등)는 실제 데이터/화면 코드와 연결되어
> 있어서 완전히 삭제할 수는 없고, 대신 "메뉴에서 숨기기"로 필요 없을 때 목록에서 감출 수
> 있습니다. 반면 "새 탭 추가"로 만든 탭은 완전히 새로운 페이지라 이름 변경/내용 수정/완전
> 삭제가 모두 자유롭습니다.

## 참여 신청 폼 → 구글 시트 연동 설정

참여 기업 연계 페이지의 "참여 신청하기" 팝업 폼에 입력된 내용은, 방문자의 브라우저가 구글
시트에 직접 접근하는 게 아니라 이 사이트의 서버가 대신 구글 시트에 기록합니다. 지금은
신청량이 많지 않은 초기 단계라 **구글 앱스 스크립트(Apps Script) 웹 앱**으로 전달하는,
설정이 쉬운 방식을 쓰고 있습니다. (나중에 신청량이 늘어나면 구글 서비스 계정 + Sheets API로
직접 연동하는 방식으로도 바꿀 수 있습니다 — 아래 "나중에 다른 연동 방식으로 바꾸고 싶다면"
참고)

1. **구글 시트 만들기** — 새 구글 시트를 만들고, 탭 이름을 `신청내역`으로 바꾼 뒤 1행에
   머리글을 정확히 아래 순서대로 입력합니다.
   ```
   제출일시 | 기업명 | 담당자명 | 부서 | 직급/직책 | 이메일 | 연락처 | 참여 희망 방식 | 만남 방식 | 문의/요청 내용 | 남기실 말씀
   ```
   **"기업 참여 방식" 관리자 화면에서 팝업 폼에 항목을 직접 추가했다면**, 그 항목들은 위
   11개 열 뒤에 추가한 순서 그대로 값이 기록되니, 머리글 행도 그 순서대로 열을 이어서
   추가해줘야 합니다(예: `... | 남기실 말씀 | 희망 시작 시기 | 예산 규모`). 항목을 표시에서
   숨겼거나 순서를 바꿨다면 그때마다 머리글도 다시 맞춰주세요.
2. **앱스 스크립트 코드 붙여넣기** — 그 시트에서 상단 메뉴 **확장 프로그램 > Apps Script**를
   엽니다. 기본으로 열려 있는 코드를 모두 지우고, 이 저장소의
   `google-apps-script/participation-form.gs` 파일 내용을 그대로 붙여넣은 뒤 저장합니다.
3. **웹 앱으로 배포하기** — 우측 상단 **배포 > 새 배포**를 누르고, 유형 선택(톱니바퀴
   아이콘)에서 **웹 앱**을 선택합니다.
   - 실행 계정: **나**
   - 액세스 권한: **전체**
   - 배포를 누르고 권한을 요청하면 승인합니다.
4. **웹 앱 URL 복사 → Vercel에 등록** — 배포가 끝나면 나오는 "웹 앱 URL"을 복사해서, Vercel
   프로젝트의 **Settings > Environment Variables**에 `PARTNERS_APPS_SCRIPT_URL`이라는
   이름으로 등록하고 저장 후 재배포합니다.
5. 나중에 `.gs` 코드를 수정할 일이 생기면, 반드시 "새 배포"가 아니라 기존 배포에서
   **관리 (톱니바퀴) > 편집(연필 아이콘) > 새 버전**으로 다시 배포해야 URL이 그대로
   유지됩니다. (새 배포를 만들면 URL이 바뀌어서 환경 변수도 같이 바꿔줘야 합니다)

`PARTNERS_APPS_SCRIPT_URL`이 비어 있으면 공개 화면에 "참여 신청하기" 버튼 자체가 표시되지
않으니, 설정 전이라도 방문자가 제출 실패를 겪을 일은 없습니다. 로컬(내 컴퓨터)에서 테스트하려면
`.env.local`에 같은 값을 추가하면 됩니다.

### 나중에 다른 연동 방식으로 바꾸고 싶다면

신청 폼 화면, "만남 방식" 등 관리자 설정, API 라우트는 연동 방식과 무관하게 그대로 유지됩니다.
실제로 어디에 어떻게 기록할지는 `src/lib/partners-submission.ts` 파일 하나에만 담겨 있어서,
나중에 신청량이 늘어나 구글 서비스 계정 + Sheets API로 직접 연동하는 방식으로 바꾸고 싶어져도
이 파일의 구현만 바꾸면 되고 다른 코드는 손댈 필요가 없습니다. 바꿀 때가 되면 다시 요청해주시면
그때 구글 클라우드 서비스 계정 발급 절차부터 안내해드리겠습니다.

## 배포 (Vercel)

1. 이 저장소를 GitHub 등에 올린 뒤, [vercel.com](https://vercel.com) 에서 새 프로젝트로
   가져옵니다. (Next.js 프로젝트는 별도 설정 없이 자동으로 인식됩니다)
2. Vercel 프로젝트의 **Settings > Environment Variables** 에서 `.env.local`에 넣었던
   `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` 두 값을 그대로 등록합니다.
   참여 신청 팝업 폼(구글 시트 연동)을 쓰려면 위 "참여 신청 폼 → 구글 시트 연동 설정"의
   `PARTNERS_APPS_SCRIPT_URL`도 함께 등록합니다 (선택 사항 — 등록 전에는 그 버튼만 안 보일
   뿐, 나머지 기능에는 영향이 없습니다).
3. Deploy를 누르면 완료됩니다. 이후에는 main 브랜치에 푸시할 때마다 자동으로 재배포됩니다.

### Vercel 요금제 관련 주의사항

Vercel의 **Hobby(무료) 플랜은 "비상업적, 개인 용도"로만 사용이 허용**됩니다.
([공식 문서](https://vercel.com/docs/plans/hobby)) 이 사이트는 원티드랩의 상업적 교육
사업(부트캠프) 브랜드 웹페이지이므로, 실제 서비스로 배포할 때는 **Pro 플랜(개발자 1인당
월 $20~)**으로 시작하는 것을 권장합니다. 사내 검토/데모 단계에서 잠깐 Hobby로 확인해보는
것은 문제없지만, 정식 운영 전에는 플랜을 전환해야 합니다.
